Affine Fusion Control · a floating-point-free plasma disruption court

The plasma verdict a safety authority can re-derive by hand.

A trained surrogate returns a confident actuation for any plasma state — including the off-distribution states where disruptions actually live — and cannot tell you which of its answers it was entitled to give. This is a compiled Swift 6.4 application that does the opposite: it returns an exact-integer verdict only where it has one, and names its refusal everywhere else. The verdict is an integer, identical on every machine, forever — not a black box no one can audit.

WIN
MISS names the branch
NOT_APPLICABLE no plasma current
NOT_MEASURED π-bracket
REFUSED non-physical

Five terminals. The court is as defined by the four it can say NO with as by the one it says YES with.

01The thesis

An invariant, not a trained surrogate.

The accepted instrument for real-time disruption avoidance is a float ML surrogate trained on offline supercomputer runs. It is confident everywhere. Ask it about a state it never saw and it extrapolates — smoothly, plausibly, without a flag. Where a currentless machine's Greenwald denominator goes to zero, it divides and keeps going.

This law does not. Where the inputs are admissible and in range, it returns an exact WIN or MISS with the binding branch named. Where the physics has no answer to give, it returns a named refusal, not a number. Where the answer sits closer to a threshold than π itself is known, it returns NOT_MEASURED_PI_BRACKET rather than picking a value.

The refusal is the product. A verdict industry whose answers its consumers cannot re-derive accumulates unreconcilable disagreement at the rate of its own growth.

Exhibit — a currentless stellarator (W7-X)
NOT_APPLICABLE_NO_PLASMA_CURRENT

A machine with no plasma current has no Greenwald limit to place. The court says so — permanently, no matter where the operating band drifts — rather than dividing by ≈0 and extrapolating a confident number. That one tile is the whole argument.

The published negative — the GPU loses on this law

On this branchy, no-multiply, exact-integer streaming law, a Metal GPU round-trip never beats the CPU up to a million agents — roughly 2× slower everywhere — while staying bit-for-bit correct the whole way. Its loss is a speed result, never a correctness one, and this negative is published on purpose.

04The limits — a court states its own

What this is, and what it is not.

not_known
τ_E and fusion gain Q are not computed — by design. IPB98 scaling carries fractional exponents that are not exactly representable. The three inequalities — Greenwald density, Troyon β, q_min — are a safety floor, never a performance or gain claim.
reported
This court operates no reactor. Every streaming trace is synthetic; every operating point is presented. There is no actuation and no I/O to a machine. The only real numbers here are the five machines' published current and minor radius; the disruption thresholds are illustrative and frozen for demonstration.
measured
The GPU loses on this law (~2× slower to 1M agents). A real, deliberately-published negative — scoped to this branchy exact-integer law, not a general claim, and not a correctness knock: parity is bit-exact and build-enforced.
verified
The study is PENDING. Its marker reads STUDY33_FUSION_CONTROL_VERDICT_PENDING — a law with synthetic traces and no device behind it has not earned more. That losing row is stated, not hidden.
reported
Mac-only, no LICENSE. Swift 6.4 (macOS 26+); no MCP, no network, nothing on the control hot path. The source is visible in the public studies repo with no LICENSE — source visible is not rights granted, and this local build is deliberately not the one that ships to the Affine.Earth cells.
05Reproduce it yourself

No account. No key. No permission from anyone.

zsh — re-derive every published figure from source
# clone the public studies repo
git clone https://github.com/gaiaftcl-sudo/uum8dSolarResearch.git
cd uum8dSolarResearch

# re-derive every published figure — 136 checks, digest-pinned
bash reproduce/validate.sh

# build & run the app: five panels, both courts, 65,536 agents / 1 kHz
cd app/FusionCourt
swift build -c release        # ~10 s, zero warnings · swift test = 27 tests / 4 suites
./verify-all.sh               # build, tests, 7 self-testing gates, figure harness
→ VERIFY_ALL_PROVEN

# grade a presented operating point — integer in, exact integer out
.build/release/FusionCourt --grade ne14=1000000 ipAmp=15000000 aMm=2000 betaNMilli=1800 qMinMilli=3000
→ verdict: WIN   pi-independent: true   exact path: int128

# drive the refusal — a currentless machine has no Greenwald limit
.build/release/FusionCourt --grade ne14=1000000 ipAmp=0 aMm=2000 betaNMilli=1800 qMinMilli=3000
→ NOT_APPLICABLE_NO_PLASMA_CURRENT
